# 困ったときは

## まず: ログで付け先を確かめる

線がどこに付いたかは、見た目だけでは分かりにくいことがあります。`BodyQvManager` の **「紐付けの結果をログに出す（確認用）」** を ON にしてワールドを上げ直すと、描いた本人の VRChat のログに、1 本ごとに次のような行が出ます。

```
[BodyQv] 付け先: （名前） (ID 1) / 部位: Head / 平均の表面距離: 0.02 m / 決め方: 始点 / …
```

| 項目 | 読み方 |
|---|---|
| 部位 | 付いた部位（Head・Neck・LeftHand など） |
| 平均の表面距離 | 線から体の表面までの平均。5 cm（既定）を超えると付きません |
| 決め方 | 手・腕 / 頭の範囲 / 始点 / 表面 / 付け根 のどれで決まったか。付け根のときは、線のどこ（描き始め・描き終わりなど）が体に触れていたかも出ます |
| 表面距離上位3 | 近かった部位 3 つと距離。狙った部位がどれくらい離れていたか分かります |

GrabQv にも同じく **「結果をログに出す（確認用）」** があり、`[GrabQv]` の行でまとまりの作成・持ち手の割り当て・解放が分かります。BodyQv + GrabQv のペンでは、まとまりの付け先（描いたとき・離したとき）と、持った・離したも出ます。

VRChat のログは `%USERPROFILE%\AppData\LocalLow\VRChat\VRChat\output_log_*.txt` にあります。確かめ終わったら、ログの設定は OFF に戻してください。

## BodyQv

### 体に描いたのに付かない（空中に残る）

- 線が体から離れていませんか。線に沿った平均で **5 cm 以内**でないと付きません。体コライダーで表面をなぞると確実です。
- ペンを持っている腕には付きません。反対の手で描くか、相手に描いてもらってください。
- 体に付ける範囲を広げたい場合は、「Surface Binding Distance」を少し大きくします。

### 顔に描いた線が首や肩に付く

- **顔の上から描き始めてください。** 頭に付けるかどうかは描き始めの位置を見ています。ひげを外側から頬へ向かって描くと、描き始めが顔から離れて頭に付かないことがあります。
- あごより下から描き始めた線は、首や胸に付きます（チョーカーのため）。

### 体の表面をなぞれない

- `BodyQvManager` の Inspector に警告が出ていないか確かめ、出ていればボタンで直してください（[レイヤーの設定](layers.md)）。
- 体コライダーは、BodyQv のペンを持っている人の画面で、3 m 以内の人にだけ出ます。
- 「Show Body Shape」を ON にすると、当たり判定の形が見えます。

### 翼など、体から外へ伸ばした線が付かない・体に貼り付く

- 線の描き始めか描き終わりが体の表面から 5 cm 以内でないと付きません。付け根を体に付けて描いてください。
- 体の表面をなぞる機能が ON だと、ペン先が表面から 1 m 離れるまで吸い付いたままになります。外側から描き始めて体で描き終えるか、「Enable Body Colliders」を OFF にしてください。
- 何本もの線で描く絵は、[BodyQv + GrabQv](bodygrabqv.md) のペンで描くと、最初の線が付けば残りも付いていきます。

### 通常の QvPen まで体に吸い付く

BodyQv のペンを両手のどちらかに持っている間は、ふつうのペンも体に吸い付きます。BodyQv のペンを置いてから使ってください。

## GrabQv

### 描いたものが持てない

- ワールド全体で 32 個のまとまりを使い切っていないか確かめてください。不要なものを消すと、次に描いたまとまりから持てます。
- 描いてすぐは、持ち手の準備に少し時間がかかることがあります。
- ログを ON にして、`[GrabQv] 持ち手を割り当て` の行が出ているか確かめてください。出ていなければ、下記の報告先へ知らせてください。

### 別々に描いたつもりのものが一緒に動く

同じペンで描いた線は、Split を押すまで 1 つのまとまりです。次のものを描く前に、ペンの **Split** ボタンを押してください。

## BodyQv + GrabQv

### 離したのに体に付かない・違う部位に付く

- 離したとき、まとまりのどこか 1 か所が体の表面から 5 cm 以内でないと付きません。体に当ててから離してください。
- 持っていた手の腕には付きません（手に持っていたものがその手に付かないようにするため）。自分の腕に付けたいときは、反対の手で持ってください。
- ログを ON にすると、`[GrabQv] まとまり … / 離した / …` の行に、付いた部位または最寄りの部位と距離が出ます。

### 別の部位に描いた線が、一緒に動いてしまう

1 つのまとまりは 1 つの部位にしか付きません。別の部位に描く前に、ペンの **Split** を押してください。

### 組み合わせにならない（体に付かない・持てない）

- `BodyQvManager` と `GrabQvManager` の両方の対象に、同じペンが入っているか確かめてください。両方の Inspector に「組み合わせて動くペン」の案内が出ていれば設定できています。
- 同じペンを対象にする `BodyQvManager` が 2 つ以上あると、組み合わせになりません（GrabQv の Inspector に警告が出ます）。

## 不具合の報告

[GitHub Issues](https://github.com/Poyotoron/EXQv/issues) へお願いします。BodyQv の付き方の不具合は、上記のログの行を添えてもらえると原因を特定しやすくなります。
