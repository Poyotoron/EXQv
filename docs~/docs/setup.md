# 設定の一覧

`BodyQvManager` と `GrabQvManager` の Inspector で変えられる項目です。既定値のままで使えるようにしてあります。

## BodyQvManager

### 対象ペン

| 項目 | 既定 | 内容 |
|---|---|---|
| Targeted Pens | Prefab 内の全ペン | 体に描けるようにする QvPen の `PenManager`。[手持ちの QvPen で使う](existing-pens.md) |

### 線の追従

| 項目 | 既定 | 内容 |
|---|---|---|
| Surface Binding Distance | 0.05 | 線から体の表面までの平均距離が、この値（m）以内なら体に付けます。大きくすると体から離れた線も付くようになりますが、空中に描いたつもりの線まで付きやすくなります |

### 頭の飾り

| 項目 | 既定 | 内容 |
|---|---|---|
| 頭の上の飾り（耳・輪など）を頭に付ける | ON | 頭の上や周りに浮かせて描いた猫耳・ヘイローなどを、頭と一緒に動かします |
| 頭の飾りの範囲の高さ | 0.40 | 頭の中心から上へ、飾りとみなす範囲の高さ（m、身長 1.3 m のアバター基準） |
| 頭の飾りの範囲の半径 | 0.22 | 頭の中心を通る上下の軸から、飾りとみなす範囲の半径（m、同上） |
| 紐付けの結果をログに出す（確認用） | OFF | 描いた線がどこに付いたか（付かなかったか）を、描いた本人のログに 1 行ずつ出します。[困ったときは](troubleshooting.md) |

### 体コライダー

| 項目 | 既定 | 内容 |
|---|---|---|
| Enable Body Colliders | ON | 体の表面をなぞって描く機能。OFF でも線の追従は効きます |
| Body Collider Layer | 23 | 体コライダーのレイヤー（22〜31）。[レイヤーの設定](layers.md) |
| Body Collider Distance | 3 | 自分から何 m 以内の人に体コライダーを出すか |
| Hips Radius 〜 Foot Radius | — | 部位ごとの太さ（m、身長 1.3 m のアバター基準）。実際には各アバターの身長に合わせて拡大・縮小します |
| Show Body Shape | OFF | ペンを持っている間、体コライダーの形を半透明で表示します（確認用） |

!!! note "太さは線の付き方にも効きます"
    部位ごとの太さは、体コライダーだけでなく、線をどの部位に付けるかの判定にも使っています。首を太くすると顔の線が首に取られやすくなるなど、付き方が変わります。変えるときは少しずつ試してください。

## GrabQvManager

| 項目 | 既定 | 内容 |
|---|---|---|
| Targeted Pens | Prefab 内の全ペン | 描いたものを持てるようにする QvPen の `PenManager` |
| 自動で区切る距離（m） | 2 | 今のまとまりからこの距離以上離れて描いた線を、自動で新しいまとまりにします。0 で無効 |
| 結果をログに出す（確認用） | OFF | まとまりの作成・持ち手の割り当て・解放・Erase ボタンでのまとまりの消去を、ログに 1 行ずつ出します |
| 押すたびに持つ／離す | ON（`BodyGrabQv` の Prefab では OFF） | ON: 押すと持ち、もう一度押すと離します（ペンと同じ持ち方）。OFF: 押している間だけ持ちます。[GrabQv: 持つ・離す](grabqv.md#hold) |

持てるまとまりの数（32）は、Prefab に用意した持ち手の数で決まります。

## BodyQv + GrabQv

組み合わせ専用の設定項目はありません。同じペンを `BodyQvManager` と `GrabQvManager` の両方の対象にすると、エディタが 2 つの管理を自動でつなぎ、そのペンが組み合わせで動きます。体への付き方は `BodyQvManager` の設定、まとまりの分け方は `GrabQvManager` の設定に従います。
