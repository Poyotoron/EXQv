# クイックスタート

ワールドに置いて、VRChat で試すまでの最短の手順です。

## 1. Prefab をシーンに置く

Project ウィンドウの `Packages/EXQv/Prefabs/` から、使いたい機能の Prefab をシーンへドラッグします。

- 体に描けるペン: `BodyQv/BodyQv`
- 描いたものを持てるペン: `GrabQv/GrabQv`

両方置いても構いません。ふつうの QvPen と並べて置くこともできます。

!!! tip "置く高さ"
    ペンは Prefab を置いた高さに並びます。床に置くとペンも床の高さになるので、手に取りやすい高さ（1.2〜1.3 m ほど）に置いてください。

## 2. BodyQv はレイヤーの設定を確かめる

BodyQv は、体の表面に沿って描けるように、近くの人の体に見えない当たり判定（体コライダー）を置きます。これがプレイヤーを押したりしないよう、衝突の設定が要ります。

1. シーンに置いた `BodyQv` の中の **`BodyQvManager`** を選びます。
2. Inspector に黄色い警告が出ていたら、その下のボタン（「Player との衝突を直す」「Pickup との衝突を直す」「surftraceMask に追加」）を押します。確認のダイアログが出るので「変更する」を押します。
3. 警告が消えれば完了です。

直すのは体コライダーのレイヤー（既定は 23 番）の行だけで、ほかの設定には触りません。詳しくは[レイヤーの設定](layers.md)を読んでください。

GrabQv にはこの手順はありません。

## 3. VRChat で試す

VRChat SDK のコントロールパネルから **Build & Test** でワールドに入ります。

- **BodyQv**: ペンを持って、自分や相手の体の上に描いてみてください。描いた人が動いても、線が付いてきます。ミラーがあると自分の体に描きやすくなります。
- **GrabQv**: ペンで何か描いてから、描いたものに手を伸ばして掴んでください。ペンの Erase ボタンの下にある橙色の **Split** ボタンを押すと、次に描く線から別のまとまりになります。

!!! note "2 人以上で試すと確実です"
    体に描いた線が相手の画面でも付いてくるか、持って動かしたものが相手の画面でも同じ位置にあるかは、2 人以上でないと確かめられません。Build & Test でクライアントを 2 つ立ち上げるか、友達に手伝ってもらってください。
