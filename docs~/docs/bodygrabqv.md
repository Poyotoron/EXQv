# BodyQv + GrabQv: 体に付けて、持って直す

BodyQv と GrabQv を 1 本のペンに組み合わせると、**描いたものが体に付いて追従し、しかも手で持って位置を直せます。** 離した場所で付け先を決め直すので、ずれた猫耳を持って頭に載せ直したり、空中で描いた翼を背中へ持っていって付けたりできます。

## 使い方

`Packages/EXQv/Prefabs/BodyGrabQv/BodyGrabQv` をシーンに置くだけです。中の QvPen が、最初から組み合わせで動きます。

BodyQv と同じく、体の表面をなぞって描くための[レイヤーの設定](layers.md)が要ります。シーンに置いた `BodyGrabQv` の中の `BodyQvManager` を選び、Inspector に警告が出ていればボタンで直してください。

!!! tip "手持ちの QvPen を組み合わせにする"
    **同じペンを `BodyQvManager` と `GrabQvManager` の両方の対象にすると、そのペンは組み合わせで動きます。** 組み合わせ専用の管理はありません。両方の Inspector に「組み合わせて動くペン」の案内が出れば設定できています。詳しくは[手持ちの QvPen で使う](existing-pens.md)を読んでください。

## 動き方

### 描く

- 描いた線は、GrabQv と同じく **Split を押すまで 1 つのまとまり**になります。
- まとまりの**最初の線**を、BodyQv と同じ判定で体の部位に付けます。体に付かなければ、その場に浮いたまま止まります。
- **2 本目以降の線は、まとまりの付け先にそのまま付いていきます。** 線を足しても付け先は変わりません。

!!! warning "体の別の部位に描くときは Split を押す"
    1 つのまとまりは、1 つの部位にしか付きません。頬に猫ひげを描いたあと、Split を押さずに肩へ線を描くと、肩の線も頭と一緒に動きます。別の部位に描く前に、ペンの **Split** ボタンを押してください。

### 持つ・離す

- 描いたものに手を近づけると掴めます（GrabQv と同じ）。持っている間は、体ではなく手に付いて動きます。
- **離すと、その場所で付け先を決め直します。**
    - 体の近くで離した → その部位に付きます。
    - 体から離れた場所で離した → どこにも付かず、その場に浮いたまま止まります。
    - 別の部位・別の人の近くで離した → そちらに付け替わります。
- 付け先を決めるときは、**持っていた手の腕は候補から外します。** 手に持っていたものが、そのままその手に付いてしまわないようにするためです。
- 手で持って体に当てたものは、**まとまりのどこか 1 か所でも体の表面から 5 cm 以内**なら、その部位に付きます。大きなものを体に添えて離すと付きます。

### 消す・後から入った人

- QvPen の消しゴム・Erase ボタン・全消去で消せます。
- 後から入った人の画面でも、体に付いたもの・浮かせたものが正しい位置に見え、持てます。
- 付いている人がワールドから抜けると、そのまとまりはその時点の位置で止まり、浮いたものとして持てます。

### 持てる数を超えたとき

持てるまとまりは、GrabQv と同じくワールド全体で 32 個までです。それを超えて描いたまとまりも、**体への追従は効きます**（持てないだけです）。

## できないこと・制限

- 1 つのまとまりは 1 つの部位にしか付きません。別の部位に描くときは Split を押してください。
- 付け先が決まるのは、まとまりの最初の線を描いたときと、持って離したときだけです。
- 持っている間は体に付いてきません。
- BodyQv の制限（関節をまたぐ線は曲がらない・揺れものには付かない など）は、そのまま当てはまります。[できないこと・制限](limitations.md)を読んでください。
