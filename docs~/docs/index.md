# はじめに

**EXQv** は、VRChat のワールドに置く [QvPen](https://github.com/ureishi/QvPen) を拡張するパッケージです。QvPen で描いた線に、ふつうの QvPen には無い動きを付けます。

入っている機能は 2 つで、1 本のペンに組み合わせることもできます。

| 機能 | できること |
|---|---|
| [**BodyQv**](bodyqv.md) | アバターの体に描いた線が、その人が動いても**体に付いたまま追従**します。頬に猫ひげ、腕にタトゥー、頭に猫耳やヘイロー、背中に翼など |
| [**GrabQv**](grabqv.md) | 描いた線を**まとまりごとに手で持って動かせます。** 盾の枠と十字を描いて、1 つの盾として持つなど |
| [**BodyQv + GrabQv**](bodygrabqv.md) | 描いたものが体に付いて追従し、**持って位置を直せます。** 離した場所で付け先を決め直します |

どちらも、ワールドに専用の Prefab を置くだけで動きます。描かれる人・持つ人の側（アバター）には何も要りません。ワールドに来た人なら誰でも使えます。

## ふつうの QvPen はそのまま

EXQv が手を加えるのは、**対象に指定したペンだけ**です。同じワールドに置いたふつうの QvPen は、何も変わらずに動きます。「ふつうのペン」「体に描けるペン」「持てるものを描くペン」を並べて置けます。

QvPen 本体のファイルは一切書き換えません。QvPen の消しゴム・全消去・後から入った人への同期も、今までどおり使えます。

## 最初に知っておいてほしいこと

!!! warning "BodyQv はアバターの見た目の表面には描けません"
    VRChat のワールドからは、アバターのメッシュ（見た目の形）を読めません。BodyQv は、骨の位置からカプセルで体の形を**おおまかに**作り、それに線を付けています。胸・髪・服のふくらみには合わず、揺れもの（髪・尻尾・スカート）には付いてきません。詳しくは[できないこと・制限](limitations.md)を読んでください。

!!! info "線は「描いた瞬間の位置関係」で付きます"
    BodyQv の線は、描き終わった瞬間に、いちばん近い体の部位に紐付きます。GrabQv の線は、描いたペンの「今のまとまり」に入ります。BodyQv のペンでは、あとから付け先を変えることはできないので、うまく付かなかったときは消して描き直してください。[BodyQv + GrabQv](bodygrabqv.md) のペンなら、持って離すと付け先を決め直せます。
