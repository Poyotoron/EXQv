# レイヤーの設定

BodyQv の**体の表面をなぞって描く機能（体コライダー）**を使うには、衝突の設定が必要です。GrabQv には必要ありません。

## なぜ必要か

BodyQv は、ペンを持っている人の画面で、近くの人の体に見えない当たり判定（カプセル）を置きます。QvPen の Surftrace は、ペン先が当たり判定に触れたときに表面へ吸い付くので、これで体の表面をなぞれるようになります。

この当たり判定は、次のようになっている必要があります。

| 相手のレイヤー | 衝突 | 理由 |
|---|---|---|
| ペン（Pickup） | **する** | ペン先が触れたことが分からないと、吸い付きが始まらない |
| Player / PlayerLocal | **しない** | 衝突すると、描かれる人・描く人が当たり判定に押される |

また、対象のペンの `surftraceMask`（吸い付く先のレイヤー）に、当たり判定のレイヤーが入っている必要があります。

## 直し方

`BodyQvManager` の Inspector に、足りない設定ごとに警告とボタンが出ます。

| 警告 | ボタン | 何を変えるか |
|---|---|---|
| 体コライダーが Player または PlayerLocal と衝突します | Player との衝突を直す | 当たり判定のレイヤーと Player / PlayerLocal の衝突を切る |
| 体コライダーが対象ペンの Pickup レイヤーと衝突しません | Pickup との衝突を直す | 当たり判定のレイヤーとペンのレイヤーの衝突を入れる |
| 対象ペンの surftraceMask に体コライダーのレイヤーが含まれていません | surftraceMask に追加 | そのペンの `surftraceMask` に当たり判定のレイヤーを足す |

ボタンを押すと確認のダイアログが出ます。**直すのは当たり判定のレイヤーの行だけ**で、ほかのレイヤー同士の設定は変えません。EXQv がボタンを押さずに設定を変えることはありません。

## 使うレイヤーを変える

当たり判定のレイヤーは、Inspector の「Body Collider Layer」で決めます（既定は **23**）。22〜31 のユーザーレイヤーから、ワールドで使っていないものを選んでください。変えたら、警告に従ってもう一度ボタンで直します。

## 体コライダーを使わない

Inspector の「Enable Body Colliders」を OFF にすると、当たり判定を出さず、この設定も要らなくなります。体に描いた線の追従はそのまま効きます（表面をなぞって描けないだけです）。

!!! warning "両手にペンを持っているとき"
    BodyQv のペンとふつうの QvPen を両手に持っていると、当たり判定が出ているため、ふつうのペンも体の表面に吸い付きます。
