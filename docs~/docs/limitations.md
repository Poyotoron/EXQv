# できないこと・制限

VRChat のワールドからできることには限りがあります。できないことを先に書いておきます。

## BodyQv

### 技術的にできないこと

| できないこと | 理由 |
|---|---|
| 髪・尻尾・スカートなど、揺れもの（PhysBone）に付ける | ワールドからは揺れものの骨の位置を読めません。揺れものの上に描いた線は、近くの体の部位（頭・腰など）に付きます |
| アバターの見た目の表面にぴったり描く | ワールドからはアバターのメッシュを読めません。体の形は骨の位置からカプセルで近似しているので、胸・髪・服のふくらみには合いません |
| 独自の骨（耳・しっぽなど、ヒューマノイド以外の骨）に付ける | ワールドから読めるのはヒューマノイドの骨だけです |

### 付き方の制限

- **関節をまたぐ線は曲がりません。** 1 本の線は 1 つの部位にだけ付きます。肩から手首まで一筆で描いた線は、腕を曲げると一部が離れます。翼などの大きな絵も 1 つの骨（背中なら胸の骨）に固く付くので、腕を動かしても翼は曲がりません。
- **体から大きくはみ出す線は、線の端が体に触れているときだけ付きます**（[BodyQv: 体に描く](bodyqv.md) の「翼・尻尾など」）。BodyQv のペンで何本もの線で描いた翼は、体に触れていない羽根の線が付きません。[BodyQv + GrabQv](bodygrabqv.md) のペンで描いてください。
- **動いている人に描くと、描いている間に動いた分だけ線がずれます。** 線の点は描いている間の位置で記録されるためです。
- **描かれた本人の画面では、通信の遅れの分だけ線の位置がずれることがあります。**
- **アバターを変えると、体型が変わった分だけ線が浮いたりめり込んだりします。**
- **アバターの大きさを変えても、線の大きさは変わりません。**
- BodyQv のペンで描いた線の付け先を後から変えることはできません。消して描き直すか、[BodyQv + GrabQv](bodygrabqv.md) のペンを使ってください。

### 体コライダー

- 吸い付くのはカプセルの表面で、見た目の表面とは少しずれます。
- 描いている間に相手が動くと、吸い付く位置も動き、線がぶれます。
- BodyQv のペンとふつうの QvPen を両手に持っていると、ふつうのペンも体に吸い付きます。
- **一度吸い付くと、ペン先が表面から 1 m 離れるまで外れません**（QvPen の仕様）。体から外へ描き出す線（翼など）は、しばらく体に貼り付いてから跳びます。外側から描き始めて体で描き終えるか、体コライダーを OFF にして描いてください。
- ヒューマノイドでないアバターには出ません（線の追従は、頭・両手・足元に対して効きます）。

## GrabQv

- **1 本のペンで描いた線は、Split を押すまで 1 つのまとまりになります。** 線どうしの距離などから自動でまとめる機能はありません（2 m 以上離れたときに区切るだけです）。
- **持てるまとまりは、ワールド全体で同時に 32 個まで**です。
- 持てる範囲は、まとまりの線を囲む箱です。形に沿った当たり判定ではないので、細長い線や L 字のものは、線の無いところでも掴めます。
- まとまりの大きさを変える（拡大・縮小する）ことはできません。
- 重なって置かれたまとまりは、どちらが掴まれるかが手の位置しだいです。狙ったものを掴むには少し離して置いてください。
- **Erase ボタンでまとまりを消すときは、線を 1 本ずつ消します。** 人がいるワールドでは、線の多いまとまりは消えきるまで少し時間がかかります。
- まとまりを消している途中でそのペンを持つと、残りの線は消えずに残ります（全員の画面で同じように残ります。もう一度消してください）。
- まとまりを消した直後（1 秒ほど）にそのペンを持つと、まれに最後の 1 本が、自分の画面では消えているのに、ほかの人の画面に残ることがあります（ふつうの QvPen で Undo の直後にペンを持った場合と同じです）。ほかの人に消しゴムで消してもらってください。

## BodyQv + GrabQv

- **1 つのまとまりは 1 つの部位にしか付きません。** 体の別の部位に描くときは Split を押してください。
- **付け先が決まるのは、まとまりの最初の線を描いたときと、持って離したときだけ**です。線を描き足しても付け先は変わりません。
- 持っている間は、体ではなく手に付いて動きます。
- BodyQv と GrabQv それぞれの制限（上記）も、そのまま当てはまります。

## 共通

- 動作を確認している QvPen は 3.3.15 です。QvPen の内部の作りに合わせて動いているので、QvPen の大きな更新で動かなくなる可能性があります。対応範囲外のバージョンでは Inspector に警告が出ます。
