# GrabQv: 描いたものを持つ

GrabQv のペンで描いた線は、**まとまり（オブジェクト）ごとに手で持って動かせます。** 誰でも持てて、離すとその場に浮いたまま止まります。持って動かしたものは、ほかの人の画面でも同じ位置に見えます。

## まとまりの決め方

1 本のペンで描いた線は、**Split ボタンを押すまで 1 つのまとまり**になります。

- 盾の枠を描き、続けて真ん中に十字を描けば、枠と十字が 1 つの盾になります。
- 次のものを描く前に **Split** を押すと、そこから先の線は別のまとまりになります。

!!! note "Split ボタン"
    各ペンの **Erase** ボタン（青い枠）のすぐ下に、**橙色の枠の Split ボタン**が付いています。ペンを持ったときに見える位置についてきます。誰が押しても、そのペンの次の線から新しいまとまりになります（全員で共有されます）。

次のときは、Split を押さなくても自動で新しいまとまりになります。

- そのペンで描くのが初めてのとき
- 今のまとまりから **2 m 以上離れた場所**に描いたとき（誰かがまとまりを持ち去った後に、元の場所で描き続けた場合など）。距離は Inspector で変えられ、0 にすると無効です
- 今のまとまりの線がすべて消されていたとき

## 持つ・離す

- 描いた線に手を近づけると掴めます。掴める範囲は、まとまりの線をすべて囲む箱です（3 cm の余白付き）。
- 離すと、その位置・向きのまま空中に止まります。重力では落ちません。
- 持っている間に、ほかの人がそのまとまりに線を描き足すこともできます。

## 消す

QvPen の消しゴム・Erase ボタン・全消去で、ふつうの線と同じように消せます。まとまりの線がすべて消えると、そのまとまりは持てなくなり、使っていた持ち手は次のまとまりに回されます。

## 持てるまとまりの数

ワールド全体で同時に持てるまとまりは **32 個**までです（Prefab に用意された持ち手の数）。それを超えて描いたまとまりは、ふつうの QvPen の線と同じくその場に残り、持てません。どれかを消すと、次に描いたまとまりから持てるようになります。

## 後から入った人

後から入った人の画面でも、まとまりは動かされた後の位置に見え、持つことができます。

## BodyQv と組み合わせる

1 本のペンを BodyQv と GrabQv の両方の対象にすると、描いたものが体に付いて追従し、持って位置を直せるペンになります。[BodyQv + GrabQv](bodygrabqv.md) を読んでください。
