# GrabQv: 描いたものを持つ

GrabQv のペンで描いた線は、**まとまり（オブジェクト）ごとに手で持って動かせます。** 誰でも持てて、離すとその場に浮いたまま止まります。持って動かしたものは、ほかの人の画面でも同じ位置に見えます。

## まとまりの決め方

1 本のペンで描いた線は、**Split ボタンを押すまで 1 つのまとまり**になります。

- 盾の枠を描き、続けて真ん中に十字を描けば、枠と十字が 1 つの盾になります。
- 次のものを描く前に **Split** を押すと、そこから先の線は別のまとまりになります。

!!! note "Split ボタン"
    各ペンの **Erase** ボタン（青い枠）のすぐ下に、**橙色の枠の Split ボタン**が付いています。ペンを持ったときに見える位置についてきます。誰が押しても、そのペンの次の線から新しいまとまりになります（全員で共有されます）。

次のときは、Split を押さなくても自動で新しいまとまりになります。

- そのペンで描くのが初めてのとき
- 今のまとまりから **2 m 以上離れた場所**に描いたとき（誰かがまとまりを持ち去った後に、元の場所で描き続けた場合など）。距離は Inspector で変えられ、0 にすると無効です
- 今のまとまりの線がすべて消されていたとき

## 持つ・離す {#hold}

- 描いた線に手を近づけると掴めます。掴める範囲は、まとまりの線をすべて囲む箱です（3 cm の余白付き）。
- `GrabQv` の Prefab では、**掴むボタンを 1 回押すと持ち、もう一度押すと離します**（ペンと同じ持ち方）。押し続ける必要はありません。
- 離すと、その位置・向きのまま空中に止まります。重力では落ちません。
- 持っている間に、ほかの人がそのまとまりに線を描き足すこともできます。

!!! tip "持ち方を変える"
    `GrabQvManager` の Inspector の **「押すたびに持つ／離す」** で選べます。

    | 設定 | 持ち方 |
    |---|---|
    | ON（`GrabQv` の既定） | 押すと持ち、もう一度押すと離す |
    | OFF（`BodyGrabQv` の既定） | 掴むボタンを押している間だけ持つ |

## 消す

QvPen の消しゴム・Erase ボタン・全消去で、ふつうの線と同じように消せます。まとまりの線がすべて消えると、そのまとまりは持てなくなり、使っていた持ち手は次のまとまりに回されます。

### Erase ボタンの長押しでまとまりごと消す {#erase-hold}

GrabQv のペンの Erase ボタンは、押している長さで消えるものが変わります。ふつうの QvPen の Erase ボタンに、**まとまりごと消す段階（SPLIT）** を足したものです。

| 押している長さ | 消えるもの |
|---|---|
| すぐ離す（0.31 秒未満） | 自分が最後に描いた線 1 本（Undo。ふつうの QvPen と同じ） |
| 0.31 秒 | **自分が最後に描いた線のまとまり**。ほかの人が描き足した線も含めて丸ごと消えます |
| 1 秒 | そのペンで自分が描いた線すべて（SELF） |
| 2 秒 | そのペンの線すべて。ほかの人の線も消えます（ALL） |

- 押している間、ボタンの左上に **SPLIT（橙）・SELF（黄）・ALL（赤）** の輪が出て、それぞれの時間で満ちていきます。消したい段階の輪が満ちたら離してください。
- Split を押した直後（次のまとまりにまだ何も描いていないとき）でも、**直前に描いたまとまり**が消えます。続けて長押しすると、1 つ前のまとまりへとさかのぼって消せます。
- 消した線は、全員の画面で消えます。
- 線の多いまとまりは、人がいるワールドでは消えきるまで少し時間がかかります（1 本ずつ消します）。

!!! note "Erase ボタンの差し替え"
    この長押しは、GrabQv が QvPen の Erase ボタンを差し替えて実現しています。`GrabQv` / `BodyGrabQv` の Prefab では差し替え済みです。手持ちの QvPen で使うときは、[手持ちの QvPen で使う](existing-pens.md)の手順で差し替えてください。GrabQv の対象でないペンの Erase ボタンは変わりません。

## 持てるまとまりの数

ワールド全体で同時に持てるまとまりは **32 個**までです（Prefab に用意された持ち手の数）。それを超えて描いたまとまりは、ふつうの QvPen の線と同じくその場に残り、持てません。どれかを消すと、次に描いたまとまりから持てるようになります。

## 後から入った人

後から入った人の画面でも、まとまりは動かされた後の位置に見え、持つことができます。

## BodyQv と組み合わせる

1 本のペンを BodyQv と GrabQv の両方の対象にすると、描いたものが体に付いて追従し、持って位置を直せるペンになります。[BodyQv + GrabQv](bodygrabqv.md) を読んでください。
